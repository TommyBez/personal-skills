# Personal Skills

Reusable skills for AI coding agents.

## Skills

- [Project Atlases](skills/project-atlases/SKILL.md): create and maintain interactive HTML process and data-model atlases grounded in a project specification or implementation.

Each skill includes a `SKILL.md` entry point and any supporting references or agent metadata.

## Use with Codex

Copy a skill folder into `~/.codex/skills/`. For example, copy `skills/project-atlases` to `~/.codex/skills/project-atlases`, then invoke `$project-atlases`.
